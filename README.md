### Project Description

The Student Grade Calculator is a Python application that:
- Calculates average grades for multiple students
- Converts numerical grades to letter grades
- Generates formatted student reports
- Provides class-wide statistics

### Features

- **Grade Averaging**: Automatically calculates the mean of multiple assignment grades
- **Letter Grade Conversion**: Maps numerical averages to letter grades (A-F scale)
- **Student Reports**: Displays individual student performance summaries
- **Class Statistics**: Provides aggregate data across all students

### How to Run

1. Ensure Python 3.x is installed on your system
2. Navigate to the project directory
3. Run the program:

```bash
python3 student_grade_calculator.py
```

### Running Tests

To run the unit tests:

```bash
python3 test_grade_calculator.py
```

All tests should pass, demonstrating proper functionality of the grade calculation and letter grade assignment functions.
